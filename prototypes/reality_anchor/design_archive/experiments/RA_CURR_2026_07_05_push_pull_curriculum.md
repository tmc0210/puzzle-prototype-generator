## Summary

本记录保存 Reality Anchor 早期 P/L 课程的第 2-4 关，以及第 6 关的强应用样本：

- `L02_FIXED_PL_PUSH_PULL_v2`：固定 P/L 下的简单 push / pull 引入。
- `L03_FIXED_PL_HANDOFF_v2`：同一箱子从 push phase 转入 pull phase 的短应用；归档后按二次人评补一格左下墙，缩短第三关不需要的开局死路。
- `L04_MOVABLE_PL_TIMING_v1`：可移动 P/L 的时机见证，先拉箱，再移动 P/L，再推箱。
- `L06_MULTI_AXIS_PL_v2`：固定 P/L 多方向应用；单箱先覆盖目标、再被拉出重开通路、最后回填，与 P/L 下拉/右拉/右推形成紧凑的撤销/恢复矛盾。

人类最终评价分别为审美 2 / 难度 1、审美 2 / 难度 2、审美 3 / 难度 2、审美 4 / 难度 4。前三者用于课程下界校准；L06 v2 可作为小空间强逻辑应用样本和反拼接校准。
