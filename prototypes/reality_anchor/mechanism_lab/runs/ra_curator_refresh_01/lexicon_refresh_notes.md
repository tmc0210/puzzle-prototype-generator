# Lexicon Refresh Notes: ra_curator_refresh_01

## 本轮结论

本轮 refresh 后，`lexicon.md` 从“结构发现集合”改成“可组合局部结构接口”。正式条目减少为 6 个：

1. `B/S 绑定债：箱资源生成刚体 footprint`
2. `刚体黏块 + 墙口：反向施力格谱系`
3. `B/S 移动边界刷产物：远程生成与门口消费`
4. `P/L 长轴墙廊：L 端余量棘轮`
5. `P/L 横向把手：玩家前格门与锚点 footprint 门`
6. `P/L pull 抽取把手：前格门、footprint 门与扫带`

## 分层变化

- `B/S 解绑定债` 不再作为顶层正式条目。它是有价值的 producer，但本轮旧证据缺少消费 probe。
- `边界刷产物的门口消费谱` 并入 `B/S 移动边界刷产物`，作为它的 consumption probe。
- `P/L 驱动 B/S 边界刷子`、`Pull 刷子 stroke 选择器` 降为 driver / 输入侧补充。
- `尾债再消费` 保留为 recipe 线索，不作为顶层结构族。

## 写法变化

每条正式条目现在都写：

- 输入条件
- 输出状态
- 自然消费方式
- 常见 shortcut
- 审美风险
- consumption probe
- 推荐 probe
- 组合例句

这些字段不是表格化填空，而是为了让 designer 检索“我需要什么输入、能产出什么、怎么接下游结构”。
