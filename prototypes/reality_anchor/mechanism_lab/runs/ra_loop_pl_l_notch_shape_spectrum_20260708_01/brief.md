# Mechanism Lab Brief: ra_loop_pl_l_notch_shape_spectrum_20260708_01

- prototype: reality_anchor
- design_space: 规范方向的 P/L L形缺角活塞 -> 去掉对称镜像后比较非对称形状扩展、目标格集合和扫带 consumer -> 输出一推即侧拉、形状门或资源移交
- seed_source: 用户指出左右 / 上下镜像由机制对称性保证，不应占 case 名额；应排除对称 case，把比较放到更多非对称内容上。
- source_boundary: 允许读取 Reality Anchor 当前规则、当前 mechanism_lab lexicon/index/backlog 和当前 run；禁止读取 design archive、人类评价、历史候选包、sampler profile、hardcoded layout template 和旧 runs，除非后续核对 provenance 时另行说明。
- structure_spectrum:
  - 规范 3-cell L：玩家站在左下缺角，`right` 后立即 `down pull`。
  - 无缺角横条：相同 `right,down` 退化为 walk，说明缺角把手必要。
  - 上横臂向前加长：仍能一推即侧拉，但新增外侧目标格。
  - 上横臂外侧目标墙：同一长横臂下，外侧目标格加墙使第二手 `force_blocked`。
  - 上横臂向后加长：检验向后尾巴不会破坏两步接口，但改变回撤占格。
  - 竖腿向下加长：仍能一推即侧拉，但最低目标格成为新增门。
  - 竖腿最低目标墙：最低目标格加墙使第二手 `force_blocked`。
  - 规范 L 外部目标格换成 B/S anchor：第二手扫带 anchor 并覆盖目标。
- do_not_repeat:
  - 不用左 / 右 / 上 / 下镜像证明覆盖度。
  - 不把横条 walk 当作成功。
  - 不把普通开放空间 L 形侧拉写成成果。
  - 不把 B/S anchor 当成本轮主机制；它只是可移动目标格 consumer。
- success_criterion: 用非对称形状扩展证明缺角活塞的目标格集合会随形状扩展而改变，并用墙 / 可移动邻物消费这些新增目标格；形成比镜像覆盖更有设计用途的结构谱。
- output_contract: 生成 cases.yml、cases.json、results.json、report.md、explorer_notes.md、proposed_families.md、curator_decision.md；正式 lexicon/index/backlog 不直接修改，改动建议写入 curator_decision.md 等待用户确认。
