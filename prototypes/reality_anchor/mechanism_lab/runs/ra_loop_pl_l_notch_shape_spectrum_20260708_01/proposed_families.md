# Proposed Families

## P/L L形缺角活塞：一推即侧拉

建议状态：`promote`

### 定义

在 P/L 场中，使用带缺角的黏块 L 形作为活塞本体。玩家初始位于缺角，先沿一个轴向推动 L 形一格；推动后，玩家仍贴着 L 形的正交邻接面，因此下一手可以立刻向侧向拉动 L 形。

这不是单箱推拉，也不是普通横条回撤。它依赖三个条件同时成立：

- 玩家站位在 L 形缺角中；
- 第一手推动后仍保留正交拉动邻接；
- 第二手拉动的目标格集合未被墙、边界或不可动链条阻塞。

### 形状变量

| 变量 | 语义 | 对应 case |
| --- | --- | --- |
| 基础 3-cell L | 最小一推即侧拉结构；两步可回返 | `base_l_triomino_success` |
| 无缺角横条 | 退化为推后走动，第二手不是 pull | `bar_no_notch_walk` |
| 横臂向前延长 | 保留侧拉，同时新增侧向外侧目标格 | `top_arm_right_success` |
| 向前横臂目标墙 | 第一手可推，第二手被新增目标格墙门阻断 | `top_arm_right_target_wall` |
| 横臂向后延长 | 保留侧拉，主要改变回撤占格和尾部扫带 | `top_arm_left_tail_success` |
| 竖腿向拉动方向延长 | 保留侧拉，但新增低位目标格和后续拉深限制 | `vertical_leg_down_success` |
| 竖腿低位墙 | 第一手可推，第二手被低位目标格阻断 | `vertical_leg_down_low_wall` |
| B/S anchor 在扫带中 | 第二手侧拉同时推动 anchor，产生目标覆盖 consumer | `base_target_bs_anchor_swept` |

### 最小 consumer

1. 正交墙门：墙位放在第二手拉动的新增目标格上，允许第一手推动但禁止侧拉。
2. 侧向扫带邻物：把 B/S anchor 或其他可动件放进侧拉扫带，侧拉本身成为推进邻物的动作。
3. 短回返活塞：基础 L 和部分延长 L 可以两步返回初始，用作可逆门控或计时器。
4. 目标覆盖：B/S anchor 被侧拉扫带移动到 goal 上，证明本族能产出非空目标效果。
