# Reality Anchor 机制语料当前索引

本文件是当前入口，给 explorer 快速避重、查找具体摆法和生成 brief。正式正文以 `lexicon.md` 为准；历史 refresh / decision 文件和旧 runs 只在核对 provenance 或审计时读取。

## B/S 边界黏合：箱组形成横条或 L 形黏块

- 一句话用途：把多个箱子推过 B/S 边界，使相邻箱子粘成横条、L 形或更大的连体块。
- 开始摆法：两个以上 crate 可相邻、排成 L 形或隔行进入 sticky 侧。
- 动后局面：相邻箱子粘住；隔行进入时仍是分开的 sticky；桥接已有端点时形成更大连体块。
- 主要接法：单行走廊、目标口宽、黏块墙口、固定 B/S 切割。
- 后续候选 / 维护备注：只有跨线顺序、边界位置或边界移动仍决定粘合形状时，才继续作为 B/S 题材。

## 固定 B/S 切割：二格黏块分成箱子和黏块

- 一句话用途：把横向二格 sticky 切成左边普通箱和右边 sticky，让左边箱子可以单独推进单格目标袋。
- 开始摆法：固定 B/S 边界切在横向二格 sticky 之间，玩家能绕到左格下方。
- 动后局面：形成 `C+M`；左格可单独推动，右格仍留在旁边；未切开的 `MM` 仍会整体移动。
- 主要接法：单格目标袋；双格袋口作为宽口反例。
- 后续候选 / 维护备注：可继续测试左格进目标后，右侧 sticky 如何挡路或进入第二个墙口。

## 固定 B/S 断桥：C 形黏块拆成两个端点

- 一句话用途：把 C 形 sticky 的左侧连接柱切开，让右侧上下端点可以分别推动。
- 开始摆法：固定 B/S 边界切过 C 形左柱，玩家能绕到右侧端点下方。
- 动后局面：右侧两个 sticky 端点彼此分开，左柱变成 crate；未切开时仍是一个 C 形连体块。
- 主要接法：单格端点目标袋；站位关闭和端点预先分离作为边界对照。
- 后续候选 / 维护备注：可测试上下端点分别进入两个目标，以及左侧 crate 柱怎样影响第二段路线。

## 黏块过墙口的通过与回推条件

- 一句话用途：比较条形、L 形和 2x2 黏块能否穿过墙口，以及进去后玩家能否走到另一侧推回来。
- 开始摆法：不同形状的 sticky 连体块位于窄口、单列通道、目标口或墙齿前。
- 动后局面：整块可能直接撞墙，也可能进入后失去反推站位。
- 主要接法：墙口宽度、前沿墙齿、端点外侧站位、2x2 单侧操作位、L 形凸角操作位。
- 后续候选 / 维护备注：若继续，应改变操作位上放置的对象或接入新的非对称形状，不补普通镜像。

## Pull 侧对象可动性：单箱与不同形状黏块

- 一句话用途：比较拉动单箱、单格 sticky 和多格 sticky 时，玩家前格、对象目标格和反向操作位分别怎样限制动作。
- 开始摆法：玩家处于 pull side，身后一格放单箱或不同形状 sticky，前方与对象目标格可分别设墙。
- 动后局面：单箱进入玩家旧格；多格 sticky 必须整体平移；拉过口后还可能到不了另一侧操作位。
- 主要接法：单格墙口袋、目标格墙、L 形远端墙、沿轴前格墙、crate 或 sticky 占住反向操作位。
- 后续候选 / 维护备注：若继续，应接实际目标口袋或比较不同对象占住反向操作位的结果。

## B/S 移动边界：箱组变为 CC、C+M 或黏块

- 一句话用途：移动 B/S 边界，把远处箱组改成 `CC`、`C+M`、`C+MM`、2x2 sticky 或两根 sticky 柱。
- 开始摆法：可移动 B/S anchor 与远处横条、竖条、L 形、2x2 或双柱箱组位于同一区域。
- 动后局面：边界停位决定哪些格是 crate、哪些格是 sticky，以及它们是否粘在一起。
- 主要接法：同一门口、低墙、列间隙或目标口比较不同箱组能否推进，以及门外会留下什么。
- 后续候选 / 维护备注：目标回填是自然方向，重点比较覆盖目标后门外还剩几格 sticky。

## P/L 锚点在横廊中的可动性

- 一句话用途：P/L 锚点在一格高横廊中能移动几次，完全由端点前方还剩几格空位决定。
- 开始摆法：水平 P/L 位于横廊，P 侧 push 或 L 侧 pull，端点前方留 0、1 或 2 格。
- 动后局面：0 格不能动，1 格只能动一次，2 格可以连续动两次；拉动后出口墙还可能封住返回路线。
- 主要接法：一次性开关、门闩、固定停位、带动 B/S anchor 到指定行。
- 后续候选 / 维护备注：可接 B/S 移动边界；不缺普通长度变体。

## P/L 横向把手：玩家前格与锚点目标格

- 一句话用途：区分玩家要走的格子、P 半格目标格、L 半格目标格和移动后返回格分别被墙挡住时的结果。
- 开始摆法：横向或竖向 P/L，玩家从 P 侧推或 L 侧拉，各相关格子可分别设墙。
- 动后局面：玩家前格被挡时无法拉；任一锚点目标格被挡时整块无法移动；首步成功后仍可能无法返回。
- 主要接法：墙位分类、移动 B/S 边界的启动条件、mixed pull chain 的 carried-crate 目标墙。
- 后续候选 / 维护备注：与 B/S 移动边界串接；不再补基础墙位矩阵。

## P/L 锚点移位：腾出旧半格并改变推拉侧

- 一句话用途：P/L 锚点移开后，旧 L 半格会腾空，邻近箱子也可能从 L 侧落到新的 P 侧。
- 开始摆法：旧 L 半格旁有目标袋或 crate，玩家移动锚点后能到达腾出的格子。
- 动后局面：旧半格成为新 push 站位；原先挡住 pull 的侧边 crate 可以从新方向推动。
- 主要接法：单格目标袋、侧边 crate 接力、两段式边界移动。
- 后续候选 / 维护备注：继续时应接具体目标或门口，不再只证明锚点会移动。

## P/L pull 抽取：玩家前格、对象目标格与侧向扫带

- 一句话用途：拉出箱子或二格对象时，同时检查玩家前格、对象所有目标格，以及侧边 blocker 能否移动。
- 开始摆法：玩家位于 pull 侧，身后放 crate、B/S anchor 或其他二格对象，前方和侧向目标格可设墙或放箱。
- 动后局面：单箱或沿轴二格对象被拉出；垂直二格对象可能被侧墙挡住；侧边 crate 会被一起推走。
- 主要接法：远程拉出 B/S anchor、从口袋拉箱、侧向带动 crate。
- 后续候选 / 维护备注：可把侧边 crate 换成 sticky，比较一起移动、合并或完全挡住拉动。

## P/L 边界交接：从 P 侧推入，再从 L 侧拉回

- 一句话用途：先把对象从 P 侧推到边界，再从 L 侧拉回，比较单箱、箱链和 sticky 连体块的差异。
- 开始摆法：对象位于 P/L 边界旁，玩家能从 P 侧推入并走到 L 侧操作位。
- 动后局面：单箱进入玩家旧格；箱链只拉回近端箱；sticky 连体块必须整体回撤。
- 主要接法：目标口袋、拉走近端箱后打开单格口、形状目标墙、单箱目标活塞顺序锁。
- 后续候选 / 维护备注：`边界活塞的对象差异`与`单箱目标活塞顺序锁`已收录；后续只接实际目标、门口或返回路线。

## P/L L 形缺角活塞：一推即侧拉

- 一句话用途：玩家站在 L 形 sticky 缺角中，横推一格后仍贴着另一条边，可以立即垂直侧拉。
- 开始摆法：带缺角的 L 形 sticky、玩家缺角站位、P/L 边界，以及第二步要移入的格子。
- 动后局面：第一步后出现立即侧拉的位置；第二步可能被玩家前格墙或 L 形目标格墙挡住，也可能带动邻物。
- 主要接法：正交墙位、短回返活塞、B/S anchor 扫带、横推后出现的侧拉操作位。
- 后续候选 / 维护备注：左右和上下镜像不作为候选；只测试新的非对称形状或被侧拉带动的对象。
