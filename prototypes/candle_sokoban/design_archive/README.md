# 蜡烛原型设计归档

本目录保存 `candle_sokoban` 中已经由人类试玩并明确标记为
`ready_for_archive` 的候选短卡。

- `candidates/`：候选审美校准卡；layout、人类原评语与人类分数以卡片为准。
- `index.yml`：只用于导航和检索，不替代候选卡与人类原评语。
- `playtest_reviews.yml`：人类试玩状态的权威来源，不复制到本目录另立一套状态账本。

归档遵循 `docs/29-design-archive-contract.md`。工作室过程报告、工具 trace、probe、
搜索日志和审查流水账不属于默认归档读取路径。
